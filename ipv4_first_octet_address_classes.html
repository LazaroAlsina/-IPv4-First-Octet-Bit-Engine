The Leading Bits Dictate The Class

Every IPv4 address has 32 bits divided into 4 octets. In classic classful addressing, the Class is determined entirely by the highest-order bits (MSBs) of the 1st Octet. Click the bit switches below to watch the decimal total and class dynamically adapt!

Quick Memorization Trick

Count the number of initial 1s before the first 0:

  • 0 ones → starts with 0: Class A (1st letter)
  • 1 one → starts with 10: Class B (2nd letter)
  • 2 ones → starts with 110: Class C (3rd letter)
  • 3 ones → starts with 1110: Class D (4th letter)
  • 4 ones → starts with 1111: Class E (5th letter)
Notice the pattern: count the leading ones, then map directly to the alphabet!

The Exact Bit Math: Why the Decimal Ranges Occur

Students often ask: "Why is Class B specifically 128 to 191? Where did those exact numbers come from?" They aren't arbitrary choices; they are the pure mathematical consequence of freezing the leading bits.

Class A Derivation (Bit 7 = 0)

Prefix: 0xxxxxxx

The highest-weight bit (27 = 128) is locked to 0. The remaining 7 bits can vary from all zeros to all ones:

Minimum: 00000000 = 0
Maximum: 01111111 = 64+32+16+8+4+2+1 = 127
Entire mathematical boundary: 0 to 127. (By convention, 0 is default route and 127 is local loopback, leaving usable unicast 1–126).

Class B Derivation (Bits 7 & 6 = 10)

Prefix: 10xxxxxx

Bit 7 is forced ON (128), and Bit 6 is forced OFF (0). The baseline is 128, and the remaining 6 bits can vary:

Minimum: 10000000 = 128 + 0 = 128
Maximum: 10111111 = 128 + (32+16+8+4+2+1) = 191
The remaining 6 bits sum to 63 (26 - 1). Therefore, 128 to 191 is non-negotiable!

Class C Derivation (Bits 7, 6 & 5 = 110)

Prefix: 110xxxxx

Bit 7 (128) is ON, Bit 6 (64) is ON, and Bit 5 (32) is OFF. Baseline sum is 128 + 64 = 192.

Minimum: 11000000 = 192 + 0 = 192
Maximum: 11011111 = 192 + 31 = 223
The 5 variable bits yield 32 combinations (0 through 31). Range: 192 to 223.

Class D & E Derivations

1110 & 1111

Following the exact same progression for 4 locked bits:

Class D (1110xxxx):
Base: 128+64+32 = 224.
Max: 224 + (8+4+2+1) = 239.
Class E (1111xxxx):
Base: 128+64+32+16 = 240.
Max: 240 + 15 = 255.
